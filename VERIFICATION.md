# Verification record

**Every entry in this file is written by Z.** It records what Z checked, on what data, at which commit, and what was found: the evidence that a person, not the agent, verified the work. The agent created the file and this header, and never writes an entry.

Entries are appended, oldest first, in this shape:

```
## <date>, at <commit>

Checked: what, and how -- a CHECKLIST.md entry by name, or anything else
Data: synthetic, and which case; or real, and never a value from it
Found: what happened, including anything that did not work
```

This file is public, like the rest of the repository, so an entry never carries a value from real data.
